# README showcase assets

Both images show the [same paper presentation](../../../examples/attention-is-all-you-need/README_EN.md).

- `slides.webp` is a 1920 × 1080 overview of slides 01, 03, 04 and 13. The four Pillow layout previews are resized without cropping or changing their content. They show the cover, Transformer architecture, attention formula and WMT14 English–German comparison.
- `editor.webp` is a 1600 × 900 screenshot of the actual web PPTD editor with slide 03 open and its title selected. It shows slide navigation, the canvas, text tools and the properties panel. The interface is captured at 16:9, then encoded as WebP without cropping or stretching.

Both README images use a 16:9 aspect ratio.

Regenerate slide previews through the documented production pipeline. Open the same project in the web editor to recapture the interface. Keep the paper version and original prompt recorded with the example.

These images do not establish PowerPoint, WPS or Keynote rendering acceptance.
